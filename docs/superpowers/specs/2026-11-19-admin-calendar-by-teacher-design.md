# Календарь админки: вид «по преподавателям»

Дата: 2026-11-19. Статус: утверждён владельцем (KOTOKOD, затем перенос в Eduson).

## Решения владельца
- Вид — для режима «Все преподаватели» в «Календаре» admin SPA. При выбранном преподавателе остаётся недельная сетка (`WeekGrid`) с фоном его графика.
- Колонки: все активные преподаватели (без служебного `is_service`), по алфавиту; в том числе без уроков на неделе.
- Строки: часы, сгруппированные по дням недели Пн…Вс. У каждого дня — часы от его самого раннего урока до самого позднего (строка = час, ~48px); день без уроков — одна строка «нет занятий».
- Фон графика работы в колонке преподавателя (закрыто — серое, окна — белые; без графика — без фона).
- Колонки с выпадающими списками из таблицы-примера не нужны; цвета таблицы не переносить.

## Контракт данных
- Каждый occurrence ответа календаря (`build_calendar`: плановые уроки и доп.уроки) получает `teacherId: number | null` — id преподавателя, который РЕАЛЬНО ведёт занятие (с учётом замены: `substitute_teacher_id or teacher_id`; для доп.урока — его преподаватель).
- `GET /api/admin/calendar` без `teacher_id` дополнительно отдаёт `availabilityByTeacher: { "<teacherId>": { "YYYY-MM-DD": [["HH:MM","HH:MM"], …] } }` — итоговые окна за окно запроса для всех активных преподавателей, у которых есть график (у кого нет — ключа нет). С `teacher_id` — `availabilityByTeacher: null` (там работает прежнее поле `availability`).
- Сервис графика: `windows_payload_many(teacher_ids, d_from, d_to)` — ровно 2 запроса (правила всех + исключения всех в диапазоне), без N+1.

## Фронт
- Новый `shared/calendar/TeacherWeekGrid.tsx` (+ стили в `calendar.css`): закреплённые слева колонка дня (объединённая по высоте дня) и колонка времени, закреплённая шапка с именами; горизонтальная/вертикальная прокрутка в контейнере как у `.cal-grid-wrap` (с `min-width: min-content` у шапки/тела).
- Блок урока: в колонке `teacherId`, `top/height` по времени и длительности внутри диапазона дня; подпись — `groupDisplay` + время, если не ровно час; цвет направления как в `WeekGrid`; статусы (cancelled/moved/done/overdue) — те же классы; пересечения у одного преподавателя — дорожки (общая функция раскладки, вынесенная из `WeekGrid`, без копипасты); клик — `onSelect` (в admin — карточка группы).
- Линия «сейчас» в сегодняшнем дне; фон окон графика по `availabilityByTeacher`.
- `AdminCalendarPage`: при `teacherId == null` и недельном виде — `TeacherWeekGrid`; иначе как сейчас. Месяц и список не меняются.
