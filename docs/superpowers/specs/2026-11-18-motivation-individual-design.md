# «Настройки → Мотивация» и причины отмен для индивидуальных занятий

Дата: 2026-11-18. Перенос из Eduson Platform (`EdusonPlatform/docs/specs/2026-10-20-eduson-motivation-payroll-design.md`, `2026-10-23-eduson-lesson-cancel-reasons-design.md`) с правилами KOTOKOD. Решения владельца — 2026-11-18.

## 1. Правила

1. **Охват.** «Мотивация» считает только занятия **индивидуальных групп** (`Group.is_individual`) и только на даты, для которых задана версия ставок (`engine.governs`). Групповые форматы и даты до первой версии считает прежний движок (`apps/payroll/calculator.py`): 500/300 малая группа, 200 за ученика, 250 за ученика на 45-минутном уроке, штраф 40 ₽ за ученика при отчёте не в день урока. В настройках групповые форматы показаны заглушкой «по правилам движка».
2. **Урок индива** — фиксированная ставка за занятие: строка направления в версии, иначе «По умолчанию». Длительность (45 мин) **не учитывается**. Никто не присутствовал — 0.
3. **Доп.урок сверх курса** у индива — по ставке урока (с персональной ставкой). **Отработка** и **сгорание** — свои ставки школы (`makeup_rate`, `burned_rate`), персональные ставки на них не действуют.
4. **Штраф** за отчёт не в день урока — настраиваемый (вкл/выкл, сумма, «за урок» / «за ученика»). Только записи преподавателя из кабинета (`acct:`, `extra:`, `makeup:`); запись из админки и сгорание не штрафуются. По умолчанию в новой версии — как в движке: включён, 40 ₽ за ученика.
5. **Прошлое не меняется.** Версия ставок — только с сегодняшнего дня или позже; исправить/удалить — только версию с сегодня или позже. Персональные ставки хранят историю периодов (`PersonalRateTerm`): правка, выключение и удаление действуют с сегодня. Существующие начисления не пересчитываются.
6. **Персональные ставки** — преподаватель × индивидуальная группа × номера уроков (диапазон или «все уроки»): «вместо ставки», «надбавка ₽», «надбавка %». Только в группе этого преподавателя. Диапазон точнее «все уроки».
7. **Отмена занятия** индива — с причиной из справочника (сторона «Преподаватель»/«Клиент», детали, для клиента — когда сообщил). Компенсация: сторона «Преподаватель» — флаг причины; «Клиент» — флаг И «сообщил не раньше дня урока». Сумма — % от ставки урока (с персональной «все уроки») или фикс. Без компенсации — начисление 0 с причиной. Решение — снимок в `LessonCancellation.compensated`.
8. **Отмена у групповых форматов** — как раньше: без причины, без записи, без оплаты.
9. **Ручная правка** суммы урока/отмены «Мотивации» ставит `is_manual`: пересчёт её не трогает (обновляет `calc_*`), пока не сменится получатель; есть «Сбросить к расчёту». У уроков прежнего движка флаг не ставится.
10. **Возврат к движку.** Индив-урок, который считала «Мотивация», а теперь нет (удалили версию, начатую сегодня; группе сменили формат), пересчитывается по правилам движка (`engine.legacy_lesson_pay`), ручная правка снимается.
11. **Конфиденциальность.** Ставки, начисления, флаг компенсации — только superadmin (API `IsSuperAdmin`); менеджер видит справочник причин без флага и вкладку отмен группы без решения о деньгах. Исключение — свои начисления в кабинете преподавателя.

## 2. Данные

- `payroll`: + `is_manual`, `calc_payment`, `calc_penalty`, `rule_note` (пусто — посчитано движком).
- `payroll_rate_versions` (`individual_rate`, `makeup_rate`, `burned_rate`, отмена, штраф), `payroll_rate_directions` (`individual_rate` направления), `payroll_personal_rates` + `payroll_personal_rate_terms` (EXCLUDE на пересечения, btree_gist), `payroll_cancellations` (начисление за отмену, ключ группа + дата + время, `planned_lesson` ON DELETE SET NULL).
- `cancellation_reasons`, `lesson_cancellations` (приложение `apps/cancellations`).
- Все модели — pghistory + `apps/changelog/registry.py`; ставки и отмены не откатываются.

## 3. Где считается

- `apps/payroll/engine.py` — чистые правила; `apps/payroll/recalc.py` — пересчёт поверх БД (`recalculate`, `recalculate_cancellations`, `recalculate_lesson`).
- Места записи (прежний движок пишет, «Мотивация» перекрывает в той же транзакции): `lessons.services.record_lesson`, `lessons.repository.update_attendance_cell` / `set_unpaid_skip` (ручную сумму не затирают), `extra_lessons.services.record` / `burn`.
- Расписание: `scheduling.repository.cancel_lesson` (запись + начисление), `reschedule`/`change_teacher` маркера, `reset_plan`, `wipe_one_offs` (будущие сироты удаляются, прошлые остаются).

## 4. API

- `GET/POST /api/admin/payroll/rate-versions`, `PATCH/DELETE …/<id>` — ответ с `recalculated`.
- `GET/POST /api/admin/payroll/personal-rates`, `PATCH/DELETE …/<id>`, `POST …/<id>/activate|deactivate`.
- `GET /api/admin/payroll` — уроки + отмены (`kind`), строгий whitelist сортировки; `POST …/<id>/reset`; `PATCH/POST …/cancellations/<id>[/reset]`.
- `GET/POST/PATCH/DELETE /api/admin/cancellation-reasons` (чтение — staff, запись — superadmin).
- `POST /api/admin/groups/<pk>/plan/<lid>/cancel` — у индива тело `{lesson_date, side, reason_id, details?, notified_on?}` обязательно (400 без причины, 409 если занятие уже сдвинуто).
- `GET /api/admin/groups/<pk>/cancellations` — вкладка группы.

## 5. Интерфейс

- «Настройки»: вкладки «Мотивация» и «Отмены уроков» (superadmin) + «Колонки таблиц» (все).
- Группа: диалог отмены с причиной (индив), вкладка «Отмены уроков» (индив).
- «Зарплата»: вид строки (урок/отмена), «Как посчитано», «вручную · расчёт N», сброс к расчёту, правка суммы отмены; в сводке — число отмен.
- Кабинет преподавателя «Зарплата»: строки отмен, пояснение «Мотивации».

## 6. Не перенесено

- Перенос занятия на дату при отмене (Eduson 6505f14) — не заказан.
- Команда `recalculate_payroll` — прошлое по решению владельца не пересчитывается.
