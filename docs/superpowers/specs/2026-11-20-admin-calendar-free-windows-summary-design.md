# Календарь админки: вкладка «Сводка» — свободные окна преподавателей

Дата: 2026-11-20. Статус: по запросу владельца (KOTOKOD, затем перенос в Eduson).

## Запрос владельца
В «Календарь» admin добавить вкладку «Сводка»: текстом показать открытые окна преподавателей.
Окна из исключений не учитывать. Показывать окна, которые открыты и в которых не стоят постоянные уроки.
Вид — блоки: заголовок — имя преподавателя, поле — сводка в формате сводки «Графика работы». Сводки удобно копировать.

## Решения (координатор, по умолчанию)
- Окна = недельный шаблон (`AvailabilityRule`), исключения (`AvailabilityOverride`) игнорируются.
- «Постоянные уроки» = слоты расписания групп (`GroupScheduleSlot`), действующие сегодня
  (`effective_from <= today` и `effective_to IS NULL or >= today`), у активных (не архивных/не завершённых) групп;
  урок занимает `[start_time, start_time + group.lesson_duration_minutes)`; преподаватель — `group.teacher_id`.
  Разовые доп.уроки, переносы, замены — не учитываются (не постоянные).
- Свободное окно = окно шаблона минус занятые интервалы (точно по минутам); куски короче 30 минут отбрасываются.
- Преподаватели: активные, не служебные (`is_service`), по алфавиту. Без шаблона — «График не задан»;
  с шаблоном, но без свободного времени — все дни «выходной»/«нет свободных окон».

## API
`GET /api/admin/work-schedule/free-windows` (IsManagerOrAdmin, как /api/admin/calendar):
```json
{"teachers": [{"id": 1, "name": "…", "has_schedule": true,
  "days": {"1": [["10:00","12:00"]], "2": [], …, "0": []}}]}
```
Ключи дней — `day_of_week` Вс=0; у преподавателя без графика `days: null`. Фиксированное число запросов
(преподаватели, правила, слоты) — без N+1; `django_assert_num_queries` в тесте.

## Фронт
- `AdminCalendarPage`: вкладки «Календарь» | «Сводка» (`ui/Tabs`, `?tab=summary`).
- «Сводка»: поиск по имени (`SearchInput`), кнопка «Копировать всё»; сетка блоков: заголовок — имя (ссылка на карточку),
  поле — текст построчно «Пн 10:00–12:00, 15:00–18:00» … «Вс выходной» (формат `formatIntervals`, порядок Пн…Вс),
  внизу «Итого N ч/нед»; кнопка «Копировать» в блоке (копирует имя + строки), текст выделяем.
- Копирование — `navigator.clipboard.writeText`, тост «Скопировано».

## Тесты
pytest: вычитание (урок внутри окна, на краю, перекрывает окно, 45-мин урок, кусок < 30 мин отброшен),
исключения не влияют, архивная группа/закончившийся слот не вычитаются, служебный/неактивный не в списке,
без графика → `days: null`, RBAC (teacher → 403), число запросов. Полный pytest; tsc в обоих SPA.
