## Часть 2. Сутки 00:00–24:00 (бэкенд графика, KOTOKOD и Eduson)

- `TimeField` не хранит «24:00» → хранение переводится на минуты от полуночи: `start_minute`, `end_minute` (`SmallIntegerField`), CHECK: `0 <= start_minute < end_minute <= 1440`, обе кратны 30; у исключения — оба NULL (день закрыт) или оба заданы; уникальность «закрыт» на дату сохраняется. Индексы — прежние.
- Миграция `availability/0002`: добавить новые поля, перенести данные из `start_time/end_time` (RunPython, обратимо), удалить старые поля и их CHECK; триггеры pghistory пересоздаются миграцией.
- Сервис и сериализатор: сетка 00:00–24:00 (`GRID_START_MIN = 0`, `GRID_END_MIN = 1440`); формат API не меняется — строки `"HH:MM"`, `"24:00"` допустим только как конец окна. Внутреннее представление интервала — пара минут (int, int). Все тесты обновить под новые границы (07:30 теперь допустимо; 24:30 и 23:45 — нет).

## Часть 3. Вид в стиле Google Calendar (фронт, KOTOKOD и Eduson)

Общее для редактора (`shared/availability`) и `WeekGrid` календарей:
- 48 получасовых слотов, высота часа ≈ 48 px; контейнер фиксированной высоты по окну с вертикальной прокруткой; шапка дней и колонка времени залипают (`position: sticky`).
- Подписи часов — на линии часа (как в GCal: «08:00» по верхней кромке часа, первая подпись скрыта); часовые линии сплошные, получасовые — светлее/пунктир.
- Шапка дня: короткое название дня (мелко, капсом) + крупная дата; «сегодня» — дата в кружке акцентного цвета.
- Линия «сейчас»: красная линия с точкой слева в колонке сегодняшнего дня (редактор — в режиме «Конкретная неделя» текущей недели; календари — как сейчас).
- Автопрокрутка при открытии/смене недели/режима: календарь — к «сейчас», если сегодня в неделе, иначе к 08:00; редактор — к min(08:00, первое окно недели/шаблона) минус 1 час.
- Редактор: при протяжке мышью/пером у верхнего/нижнего края контейнера — автопрокрутка (как в GCal).
- `grid.ts`: `GRID_START_MIN = 0`, `SLOT_COUNT = 48`; `slotLabel(48) = "24:00"`.
- Цвета — токены своего проекта (KOTOKOD / Eduson), «окно/закрыто» как сейчас; линия «сейчас» — существующий токен ошибки/danger проекта. Токены — в обоих `tokens.css`.
